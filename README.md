Après avoir passé les vacances à apprendre python il était temps de faire quelques projets dont je commence par la calculatrice. Au début j'ai créé un environnement 
virtuel << env1 >> dans lequel je voulais faire le dit projet mais il y a eu des problèmes dès la création de env1 c.a.d son activation. C'était dû à Windows pour 
des raisons de sécurité. Dans ce cas ouvrez powershell en tant qu'admin et taper :
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned et après avoir finis : Set-ExecutionPolicy -ExecutionPolicy Undefined.

Maintenant tout est prêt pour pouvoir utiliser env1 mais vous le voyez pas, pourquoi ? parce que ON VERSIONNE CE QUI EST ECRIT PAS CE QUI EST GENERE OU INSTALLE
donc sur votre propre machine vous pouvez créer env1.
